## 📌 About

This repository contains my **Deep Learning Laboratory experiments** completed as part of my B.Tech in Artificial Intelligence and Data Science.

It includes practical implementations of neural networks, image processing, computer vision, transfer learning, and recurrent neural networks using Python and TensorFlow/Keras.

The objective is to understand deep learning concepts through hands-on implementation, model training, evaluation, and performance comparison.

## 📚 Experiments

| No. | Experiment | Concepts & Techniques |
|:---:|---|---|
| 01 | Linear Regression | Prediction, MSE, Regression Plot |
| 02 | Image Processing | Histogram Equalization, Morphological Operations |
| 03 | Feed Forward Neural Network | CIFAR-10, Three Hidden Layers, Activation Comparison |
| 04 | FFNN with Initialization & Regularization | Xavier, Kaiming, Dropout, L1, L2 |
| 05 | Convolutional Neural Network | MNIST, Basic CNN, Deep CNN |
| 06 | Transfer Learning using VGG19 | Feature Extraction, Fine-Tuning |
| 07 | Time Series Forecasting | NIFTY 50, LSTM, Stock Price Prediction |
| 08 | Sentiment Analysis using Simple RNN | IMDB Movie Reviews, Text Classification |
| 09 | RNN, LSTM and GRU Comparison | Sentiment Analysis, Model Performance Evaluation |

## ⚙️ Installation & Setup

Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
cd Deep-Learning-Lab
```

Install the required libraries:

```bash
pip install tensorflow numpy pandas matplotlib scikit-learn opencv-python pillow
```

Launch Jupyter Notebook:

```bash
jupyter notebook
```

Open the required experiment notebook and run the cells.

## 📊 Datasets

The experiments use publicly available datasets, including:

- CIFAR-10 – Image classification
- MNIST – Handwritten digit recognition
- NIFTY 50 – Stock market time-series data
- IMDB – Movie review sentiment analysis

Dataset files may need to be downloaded separately. Refer to the respective experiment notebooks for dataset filenames and loading instructions.

## 🎯 Learning Outcomes

- Understand neural network architectures and activation functions.
- Implement and compare FFNN, CNN, RNN, LSTM and GRU models.
- Explore weight initialization and regularization techniques.
- Apply transfer learning using pretrained VGG19.
- Perform image enhancement and morphological operations.
- Work with time-series forecasting and text classification.
- Evaluate models using accuracy, loss and other performance metrics.
